# Stock Observer Application

## Summary
Stock Observer is a platform where people can find relevant and up to date information about the desired product they are looking for. 

This solution is a frontend application built with NextJS and 3rd party API providing stock data.

## MVP Plan
The MVP will contain a frontend application with the following pages and features.

### Pages:
- Home page with the search bar
- Dedicated page to the selected stock

### Features:
- Searching stocks
- List info about the selected product
- Visualize prices for a selected interval (implementation is in progress)
- Bookmark favourites (to be implemented soon)
- Light mode / Dark mode

## Application structure
### Stacks:
- NextJS with TS
- Tailwind CSS

## First steps
1. Clone the repository using HTTPS link or SSH.
2. Install node version manager then install the Node version from the `.nvmrc` file.
3. Install packages using:
  ```bash
  npm install
  ```
4. Start the application on your local machine with:
  ```bash
  npm run dev
  ```
